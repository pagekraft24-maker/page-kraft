# page-kraft.de

Statische Version der Pagekraft-Website (Original-Build aus Readdy), gehostet auf Vercel.

- `index.html` – Startseite (vorgerendert)
- `stadt/*.html` – 28 Stadt-Seiten (vorgerendert, eigene Title/Description/Canonical)
- `assets/` – Original-JS/CSS
- `vercel.json` – Clean URLs, SPA-Fallback, Security-Header
- `robots.txt`, `sitemap.xml`, `llms.txt`, `llms-full.txt`
